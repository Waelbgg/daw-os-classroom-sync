Ficha técnica del proyecto

Problema

Al bloquearse el calendario académico, revisar Classroom curso por curso se convirtió en una tarea manual y desordenada. Era fácil pasar por alto una entrega.

Solución implantada

Google Apps Script consulta los cursos y tareas de Classroom y los sincroniza con «Tareas y entregas» en Notion. La vista centralizada permite revisar el conjunto desde el móvil y se actualiza cada 15 minutos.

Consulta y diagnóstico trabajados

comprobarClassroom() y listarTareas(): comprobar acceso, consultar cursos y recuperar títulos, fechas e identificadores.

probarNotion(), diagnosticoNotion(), comprobarPropiedades(), pruebaGuardado() y guardarTokenNotion(): configuración, conexión, diagnóstico y pruebas de almacenamiento.

Sincronización y automatización

sincronizarClassroomConNotion() consulta los cursos, revisa las tareas y contrasta sus datos con Notion. Los IDs de Classroom permiten reconocer registros existentes y prevenir duplicados. instalarTriggerSincronizacion() configura el ciclo periódico de 15 minutos.

APIs, configuración y datos

Classroom API proporciona cursos, tareas y estados de entrega visibles para la cuenta. Notion API REST permite consultar y mantener los registros. PropertiesService guarda el token fuera del código y UrlFetchApp realiza las peticiones HTTP.

Estado y límites de la validación

Una ejecución real completó la revisión de 8 cursos y 80 tareas: 0 creadas, 0 actualizadas, 80 sin cambios y 0 omitidas. Esto valida consulta, comparación y detección de tareas ya sincronizadas en ese conjunto. Al no haber cambios detectados, ese ciclo no ejercitó creación ni actualización.

Decisiones técnicas

Integración desacoplada, IDs externos, prevención de duplicados y actualización en lugar de creación repetida. Configuración sensible fuera de la lógica principal y funciones de diagnóstico para permisos, configuración y comunicación.

Aprendizajes y valor profesional

JavaScript aplicado a sistemas, automatización, consumo de APIs REST, autenticación por tokens, comunicación HTTP, gestión de errores, procesamiento de datos, bases de datos, arquitectura, documentación y Git. Experiencia práctica abordando una necesidad real mediante integración de plataformas.
